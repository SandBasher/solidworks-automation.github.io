Macro or Solidise

Use the right tool for the size of the job.

Macros are best when

You need a one-click helper for an active document, a personal workflow or a focused export rule.

Solidise is best when

You need local-first file browsing, previews, BOM visibility, where-used search and repeatable batch export across folders.

When macros become a workflow

Use Solidise for indexed folders, BOM visibility, where-used search and repeatable batch export.

Start with a macro for a narrow task. Move to Solidise when the task spans many files, assemblies or team handoffs.

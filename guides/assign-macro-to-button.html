Assign a SOLIDWORKS Macro to a Toolbar Button

Turn a frequently used SOLIDWORKS macro into a one-click toolbar command.

Toolbar setup

  1. Save the macro in a stable local folder.
  2. Open Tools > Customize.
  3. Choose the macro command button and drag it to a toolbar.
  4. Browse to the macro, choose main as the method and set an icon if desired.
  5. Test the button on copied files.
